# Assets

This directory stores handcrafted visuals for the Nyan Cat Space site.

- `images/` — static screenshots or illustrations generated by the project owner.  
- `nyan/` — Nyan Cat sprites or GIFs. Credit the original Nyan Cat creators (Chris Torres / PRguitarman) when using canonical art.  
- `ascii/` — ASCII art or text-based visuals. Include attribution if sourced externally.

Keep each asset ≤ 200 KB. Document the origin of every non-original file inside the corresponding subdirectory README.
